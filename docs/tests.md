## LottoTest

### 유효성 검사 테스트 (Lotto 생성)

`Lotto.of()` 메서드(또는 생성자)가 비즈니스 규칙을 올바르게 검증하는지 확인하는 테스트입니다.

| 테스트 항목        | 테스트 케이스 (`Lotto.of()` 입력 값)          | 기대 결과                      |
|:--------------|:-------------------------------------|:---------------------------|
| **번호 개수 초과**  | `List.of(1, 2, 3, 4, 5, 6, 7)` (7개)  | `IllegalArgumentException` |
| **번호 개수 미만**  | `List.of(1, 2, 3, 4, 5)` (5개)        | `IllegalArgumentException` |
| **중복된 숫자 포함** | `List.of(1, 2, 3, 4, 5, 5)`          | `IllegalArgumentException` |
| **번호 범위 이탈**  | `List.of(0, 2, 3, 4, 5, 55)` (0과 55) | `IllegalArgumentException` |

### 기능 테스트 (Lotto 메서드)

| 테스트 대상 메서드                    | 테스트 케이스 (입력)                                   | 기대 결과 (반환 값) |
|:------------------------------|:-----------------------------------------------|:-------------|
| `isIncluding(Integer target)` | 로또: `List.of(1, 2, 3, 4, 5, 6)`, 타겟: `3`       | `true`       |
| `isIncluding(Integer target)` | 로또: `List.of(11, 22, 33, 34, 35, 36)`, 타겟: `7` | `false`      |

## PaymentTest

- `Payment` VO가 유효한 금액 범위 및 단위(1,000원)를 만족하는지 검증하고, 구매 개수를 올바르게 계산하는지 확인합니다.

**유효성 테스트**

| 테스트                    | 설명                                                           |
|:-----------------------|:-------------------------------------------------------------|
| `정해진_숫자_범위를_벗어난_경우_예외` | 구매 금액이 정해진 범위(e.g., -100, 0, 2000000)를 벗어나면 예외가 발생하는지 확인합니다. |
| `천_단위_숫자가_아닌_경우_예외`    | 구매 금액이 1,000원 단위가 아닐 경우 (e.g., 3100) 예외가 발생하는지 확인합니다.        |

**기능 테스트**

| 테스트                | 설명                                                       |
|:-------------------|:---------------------------------------------------------|
| `구매한_만큼_로또_카운트_계산` | 구매 금액(e.g., 12,000원)에 따라 로또 구매 개수(12개)를 정확히 계산하는지 확인합니다. |

### WinningLottoTest

- `WinningLotto` VO가 당첨 번호와 보너스 번호의 중복을 검증하고, 구매한 로또와 비교하여 정확한 등수를 판별하는지 검증합니다.

**유효성 테스트**

| 테스트                       | 설명                                             |
|:--------------------------|:-----------------------------------------------|
| `보너스_번호_로또_번호_중복_시_예외_발생` | 보너스 번호가 당첨 번호 6개 중 하나와 중복될 경우 예외가 발생하는지 확인합니다. |

| 테스트            | 설명                                                                 |
|:---------------|:-------------------------------------------------------------------|
| `당첨_등수_확인_테스트` | 특정 로또 번호와 당첨 번호/보너스를 비교하여 올바른 등수(e.g., SECOND, MISS)를 반환하는지 확인합니다. |
